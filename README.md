# Trainings-Studio

Ein Offline-Trainingsplaner als Web-App: erstellt Trainingspläne für wechselndes Equipment, ohne Account und ohne Abo. Läuft direkt im Browser und ist als PWA installierbar.

## Funktionen

- Einzelpläne und Mehrwochen-Programme
- Auswahl nach Anzahl der Übungen mit geschätzter Dauer
- Supersätze (Antagonisten), zuschaltbare Finisher (Core oder Kondition)
- Trainingslog mit Gewicht und Wiederholungen je Übung
- Fortschritts-Verlauf und Gewichts-Grafik pro Übung
- Körperwerte-Verlauf (Gewicht, Körperfett)
- Umfangreiche Übungsdatenbank mit Ausführungshinweisen
- Eigene Übungen, Favoriten, Kommentare
- Export und Import der Daten (für Backup und Gerätewechsel)

## Nutzung

Die App läuft ohne Installation im Browser. Alle Daten werden lokal im Gerät gespeichert. Über die Export-Funktion lässt sich ein Backup als Datei sichern und auf einem anderen Gerät wieder importieren.
