Speichern & Exportieren

Daten sichern

Lokal gespeicherte Browserdaten können gelegentlich durch System-Updates gelöscht werden. Nutze regelmäßig „Exportieren", um ein Backup als Datei zu sichern.

So nutzt du das Tool dauerhaft

Home-Bildschirm App: Öffne die Webseite im Browser deines Smartphones. Tippe auf das Teilen-Symbol (iOS) bzw. das Menü (Android) und wähle „Zum Home-Bildschirm". Dann startet das Tool wie eine native App.

Als PDF sichern/drucken: Erstelle einen Trainingsplan, tippe auf „Als PDF / Drucken" und sichere den Plan direkt in deinen Dateien.

Regelmäßig exportieren: Sichere deine erstellten Programme, Notizen und Körperwerte als Datei, um sie jederzeit wiederherstellen zu können.
